# my-portfolio — Персональне портфоліо Full Stack Developer

Адаптивний сайт-портфоліо, створений на HTML5, CSS3 та Bootstrap 5 для публікації на GitHub Pages.

## Структура проєкту

- `index.html` — головна сторінка портфоліо (Header, Hero, About Me, Tech Stack, Projects, Contact)
- `static/images/favicon.ico` — власний фавікон сайту
- `static/lib/bootstrap-5.0.2-dist/` — стилі та скрипти Bootstrap 5
- `static/lib/jquery-4.1.0.min.js` — бібліотека jQuery
- `static/styles/reset.css` — скидання базових стилів браузера
- `static/styles/styles.css` — власні стилі, адаптивність та світла/темна тема
- `static/scripts/main.js` — перемикання теми, фільтрація проєктів та анімації прокручування
- `static/files/CV_Yaroslav_Sorokotiaga.html` — резюме для завантаження (Download CV)

## Публікація

Сайт опубліковано через **GitHub Pages** з гілки `main` (коренева папка `/`).
